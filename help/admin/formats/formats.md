# 格式概述 {#formats-overview}

格式是一种保存的模板（或文件），它使用宏来组织发送到目标的数据内容。 格式类型包括[!DNL HTTP]格式和文件格式。 [!DNL HTTP]格式使用[!DNL POST]或[!DNL GET]方法在[!DNL JSON]对象中发送数据。 文件格式通过[!DNL FTP]以文件形式发送数据。 每种格式使用的宏允许您设置文件名、定义文件标题和组织数据文件的内容。 在管理员[!DNL UI]中，您可以在设置客户目标时创建、保存和重复使用格式。
